SUMUWW Windows 0.57.27 / Android 0.6.77 (versionCode 137)

Connection maintenance corrections
- Keep a synchronized native connection when an optional peer-address reply arrives after the local query timer. Late duplicates are ignored without importing their address hints. Address scope, format, native block validation and traffic checks remain applicable.
- Authenticate the original previous-v4 hello as well as the current hello. Preserve common native block/transaction/address transport while excluding incompatible signing policies from the current BLS signing pool. Outgoing probes can retry the existing native transport.
- Add opt-in local Windows session tracing for diagnosis. It is disabled by default and is not transmitted to peers.

Consensus unchanged from Windows 0.57.26 / Android 0.6.76
SHA-256d PoW, issuance, wallets, difficulty, reward maturity and transaction validation are unchanged. The BLS rule still activates at height 9000 and selects 10% of parent/height contexts; it is not a fixed ten-block interval. Signing, team selection, split-linkage and registered-history validation are unchanged. Native transport compatibility does not bypass the proof required for a selected block.

Verification for this revision
- 175 network regression tests passed.
- Four real-TCP previous-v4 compatibility tests passed, including refusal of an unsigned selected block.
- The installed Windows application retained the same test TCP connection through a six-second address-reply delay and a thirty-second observation.
- Eight actual external peer process identities stayed connected and synchronized for about seven minutes; temporary loopback test peers were excluded. More than eight external peers and the full historical fourteen-to-eight change remain unverified.
- Ten frozen native boundary self-test checks passed. See VERIFICATION.txt for the complete release-build checks.
- Android 0.6.77 is built and signed with the existing update lineage. Its Python transport regressions passed with the Windows cryptography backend. This exact revision has not been installed or tested on the physical phone because no ADB device was attached. No physical-device test is claimed for 0.6.77.

Installation
Windows: close SUMUWW and extract the complete ZIP, retaining _internal and the existing data directory and encrypted wallets.
Android: install the signed APK over the existing org.sumuww.miner application. Do not uninstall or clear its data to update.
Keep node data and separate boundary signing state together. Do not publish wallet passwords, recovery words or signing keys.
