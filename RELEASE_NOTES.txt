SUMUWW Windows 0.57.26 / Android 0.6.76 (versionCode 136)

Random BLS block-signature linkage from height 9000
- Each parent/height context selects a signature-required block with 10% probability, not a fixed ten-block interval.
- Three distinct node identities and observed IPs provide actual BLS signatures. Their aggregate is split and linked to the most recent selected ancestor.
- Ordinary intervening blocks retain native PoW and transaction checks. Registered-history conflicts remain rejected. Signatures do not add a work bonus.
- Final signatures are collected after valid PoW is found, before registration and propagation. Pre-PoW key delivery and zero signing delay are not guaranteed.

Discovery, transport and lifecycle
- Large proofs use authenticated multipart transport and improved response verification processing.
- Default direct-peer count limits, signature-relay pending-call count limits, and discovery-cache count/size limits were removed.
- Active queries and waiters are retained. Finished, cancelled and idle requests are cleaned up; failed discovered contacts are removed without evicting healthy connections.
- Frame, transaction and block validation, per-peer traffic management and explicit operator CLI limits remain separate.

Compatibility and platform corrections
- Pre-9000 databases with no activated block/proof/registration can safely update their policy marker while preserving history, UTXOs and balances.
- Databases already using the former policy after activation are refused rather than silently reinterpreted. Do not delete them; retain backups and obtain migration guidance.
- Valid existing common-history coins remain transferable. Old software without the required certificate cannot supply a selected block. Rewards existing only on a rejected branch are not spendable on the accepted chain.
- Android-specific network, handshake, DHT, cache and locale adapters are preserved alongside common consensus updates.
- Diagnostics, v4/9000 documentation, whitepaper images and package contents have been refreshed.

Updating
- Windows: close SUMUWW, extract the complete ZIP, and retain the saved data directory and encrypted wallets.
- Android: install the signed APK over the existing org.sumuww.miner app. Do not uninstall or clear app data.
- Preserve the node database and its separate boundary signing state together. Never publish keys, recovery words or passwords.

Verification
- Prior source audit: 1181 Windows tests, 11 additional policy/lifecycle tests and 21 Android emulator tests passed.
- These are project-run tests, not a claim of independent audit, worldwide responder coverage/convergence or complete 51% attack protection.
- Release build and installation verification are recorded separately for these exact files.
