Mining history and block APIs report new issuance, transaction fees and the total block reward separately. A wallet's own received amount remains separate from block totals. Verified startup and stored-branch replay restore historical fee data. Unknown or partially claimed component payments are not guessed.

The node provides 28 RPC methods and 11 REST routes, including fee estimation and signed-transaction validation, acceptance and relay. Automatic fees use the current local pending queue and block capacity. 1 yugeon = 0.00000001 SMW.

English is the default. Current documentation is available in all 34 supported languages. Both Android editions are prepared as installation files only. Matching application packages, source archives and checksums are available in the new GitHub releases linked from the repository README.
