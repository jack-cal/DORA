# SUMUWW · 0.57.43 / 0.6.92

Добавлены запрос комиссии, проверка перед отправкой, состояние замены RBF и чтение данных в порядке блоков. Замена проверяется до удаления ожидающих транзакций. Мультиподпись и блокировка выходов реализованы для изолированных испытаний активации; в публичной сети они пока не активированы.

1 SMW = 100 000 000 yugeon. Автоматический расчёт предлагает три уровня по локальным наблюдениям, не гарантируя время подтверждения. Ставку в yugeon/vB можно ввести вручную. Перед отправкой проверьте окончательную комиссию и итог в SMW. Отклонённая транзакция не уменьшает баланс.

`1 yugeon = 0.00000001 SMW`

`1 SMW = 100,000,000 yugeon`
