# SUMUWW · 0.57.43 / 0.6.92

Зангилаанд шимтгэл лавлах, илгээхийн өмнөх шалгалт, RBF орлуулалтын төлөв болон блокийн дарааллаар өгөгдөл унших боломж нэмэв. Хүлээгдэж буй гүйлгээг устгахаас өмнө орлуулах гүйлгээг шалгана. Олон гарын үсэг болон түгжээтэй гаралтыг тусгаарласан идэвхжүүлэлтийн туршилтад хэрэгжүүлсэн; нийтийн сүлжээнд хараахан идэвхжээгүй.
