# SUMUWW · 0.57.43 / 0.6.92

Чвор додаје упите о накнадама, проверу пре слања, стање RBF замене и читање података редоследом блокова. Замена се проверава пре уклањања трансакција на чекању. Вишеструки потписи и закључани излази примењени су за издвојене тестове активирања; још нису активни на јавној мрежи.

1 SMW = 100.000.000 yugeon. Аутоматске накнаде нуде три нивоа на основу локалних запажања, без гаранције времена потврде. Стопу у yugeon/vB можете унети ручно. Пре слања проверите коначну накнаду и укупан износ у SMW. Одбијена трансакција не умањује стање.

`1 yugeon = 0.00000001 SMW`

`1 SMW = 100,000,000 yugeon`
