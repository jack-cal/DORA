# SUMUWW standalone wallet — release withdrawn

[All components](../README.md)

Android wallet releases 1.0.7 through 1.0.9 validated the affected height-9000 chain rule and were withdrawn with the node releases. No verified replacement wallet has been released.

Preserve your existing encrypted wallet, recovery material and application data. Do not uninstall the wallet or clear its data merely because the release was withdrawn. Do not treat an earlier wallet as a verified replacement for a chain using the height-9000 rule.
