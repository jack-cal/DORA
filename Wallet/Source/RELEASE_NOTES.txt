Connection recovery and synchronization update — 2026-10-24

Windows ordinary wallet 1.0.2 and Android Wallet Current 1.1.2 now include
the connection and synchronization fixes from full-node core 0.57.38 /
Android 0.6.88. Verified contacts survive temporary failures. Retry failures
are counted once, and idle-response timeouts cannot count as successful replies.
Missing inbound listening addresses are discovered and verified before sharing.
Public outgoing handshakes and idle responses allow up to 120 seconds; partial
frames retain their shorter deadline. Validated ancestry is reused only for the
same chain snapshot, height and hash. Background proof-history work yields to
other tasks so it does not unnecessarily delay network handling.

The Windows wallet is rebuilt with the shared current desktop core. Android
retains its platform adapters and uses the matching Android core changes.
Wallet formats, addresses, consensus rules and saved language preferences are
unchanged. All 34 offline UI languages remain available. No external automatic
translation service was used. No new UI strings are introduced by these fixes.

Android retains application ID org.sumuww.wallet.current and versionCode 13,
with the same Wallet Current signing certificate for in-place updates from
1.1.0 or 1.1.1. It does not replace the withdrawn org.sumuww.wallet application.
Windows data remains at %LOCALAPPDATA%/SUMUWW/Wallet-PC.

Release downloads: https://github.com/jack-cal/SUMUWW/releases/tag/wallet-pc-v1.0.2
and https://github.com/jack-cal/SUMUWW/releases/tag/wallet-android-v1.1.2. Earlier versions remain a separate historical record. See LOCAL_REPAIR_VERIFICATION.md in the
suite documentation for current verification results and limits. Earlier
physical-device and live-network measurements do not certify this new build.
