# SUMUWW PC — release withdrawn

[All components](../README.md)

Windows releases 0.57.24 through 0.57.30 that implemented the height-9000 block-signature rule were withdrawn because their signing sequence did not match the intended design. No corrected Windows node has been released.

Earlier Windows releases predate the height-9000 rule and are historical records, not compatible replacements for a chain using that rule. Preserve your existing wallet and node data. Do not use a withdrawn or earlier build to mine, validate or transfer on a chain requiring the unverified rule.
