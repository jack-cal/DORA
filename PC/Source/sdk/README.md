# Key-free source reference

Optional developer reference only; excluded from frozen executables and Android production modules. It assembles explicitly supplied inputs/outputs, exposes digests, attaches and verifies supplied signatures, and serializes transactions. It never signs, loads keys, accesses a node, selects inputs, sweeps funds or runs a customer ledger. Add the source root and `sdk` to Python's module path. See `EXCHANGE_INTEGRATION.md` for the exact format and public vectors.
