# SUMUWW · Зангилааны ажиллагаа

SUMUWW PC 0.57.46 · Зангилаа гинжний өгөгдлийг шалгаж, хадгалж, дамжуулж, лавлах боломж олгоно.

## Сүлжээ ба хаяг

Нийтийн сүлжээ `sumuww`, дотоод өөр нэр нь `dora`. Доорх эхлэл блокийн хэшийг шалгана. Үндсэн хаяг witness v0 P2WPKH болон шахсан secp256k1 нийтийн түлхүүрийн HASH160 ашиглана. Memo, tag заавал хэрэггүй. Буруу сүлжээ, хүчингүй checksum-тай хаягийг няцаана. HD хүлээн авах/хариултын салаа, индексийг тэмдэглэнэ; Bitcoin-ийн түлхүүр гаргах замтай адил гэж үзэхгүй.

## Нэвтрэх эрх ба хязгаар

Хувийн Bearer token ашиглан тоон loopback `127.0.0.1:18443` дээр RPC-г зориуд асаана. Хэтэвч нээх, алсаас гарын үсэг зурах боломж олгохгүй. Дотоод үйлчилгээ эсвэл баталгаажуулсан туннель ашиглана; браузерын Origin/Referer хүсэлтийг няцаана. JSON-RPC нь POST `/rpc`, объект/массив `params`, `id` ашиглана; мэдэгдэл HTTP 204 буцаана. Хязгаар: бие 8004096 байт, толгой 8192, багц 16, зэрэг хүсэлт 16, хугацаа 10 секунд; limit 1–1000, offset 0–1000000. 28 арга, 11 REST замтай.

## Гүйлгээ, блок хайх

`getrawtransaction` идэвхтэй хэлхээ, mempool хайна; зөвхөн хаягдсан салаанд байгаа гүйлгээг хайхгүй. Оролт өмнөх гаралтыг заана, ганц илгээгчийн хаяг биш. `getblock` Boolean `verbose` авна; хадгалсан идэвхгүй блок `active=false`, `confirmations=-1` байна. Түүхий гүйлгээг блокийн хэшээр авч болно. `findspendingtransaction` зөвхөн идэвхтэй хэлхээний батлагдсан зарлагыг хайна; null нь ашиглах боломжийн баталгаа биш. `include_mempool=true`-тай `gettxout` шалгана. Баталгаа, идэвхтэй төлөв хэлхээ өөрчлөгдөхөд солигдож болно.

## Шалгалт

Хамаарлуудыг суулгаад эх кодоос python examples/node_contract.py ажиллуулна. Нийтэд ил туршилтын түлхүүр, түр regtest ашиглан илгээлт, татгалзалт, баталгаажуулалт, дахин зохион байгуулалт, өгөгдөл хадгалалтыг шалгана. Бодит хөрөнгө, хэрэглэгчийн профайл, гарын үсгийн төхөөрөмж ашиглахгүй.
