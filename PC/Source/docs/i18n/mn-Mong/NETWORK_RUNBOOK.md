SUMUWW PC 0.57.46 · ᠵᠠᠩᠭᠢᠯᠠᠭ᠎ᠠ ᠨᠢ ᠥᠭᠭᠥᠭᠳᠡᠯ ᠢ ᠰᠢᠯᠭᠠᠵᠤ᠂ ᠬᠠᠳᠠᠭᠠᠯᠠᠵᠤ᠂ ᠳᠠᠮᠵᠢᠭᠤᠯᠤᠨ᠎ᠠ᠃

## ᠰᠦᠯᠵᠢᠶ᠎ᠡ ᠪᠠ ᠬᠠᠶᠢᠭ

ᠨᠡᠶᠢᠲᠡ ᠶᠢᠨ ᠰᠦᠯᠵᠢᠶ᠎ᠡ `sumuww`᠂ ᠳᠣᠲᠣᠭᠠᠳᠤ ᠨᠡᠷ᠎ᠡ `dora`᠃ ᠳᠣᠣᠷᠠᠬᠢ ᠡᠬᠢᠯᠡᠯ ᠪᠯᠣᠺ ᠤᠨ ᠬᠡᠱ ᠢ ᠰᠢᠯᠭᠠᠨ᠎ᠠ᠃ ᠬᠠᠶᠢᠭ ᠨᠢ witness v0 P2WPKH᠂ ᠰᠢᠬᠠᠭᠰᠠᠨ secp256k1 ᠨᠡᠶᠢᠲᠡ ᠶᠢᠨ ᠲᠦᠯᠬᠢᠭᠦᠷ ᠦᠨ HASH160 ᠠᠰᠢᠭᠯᠠᠨ᠎ᠠ᠃ Memo᠂ tag ᠵᠠᠪᠠᠯ ᠬᠡᠷᠡᠭ ᠦᠭᠡᠢ᠃ ᠪᠤᠷᠤᠭᠤ ᠰᠦᠯᠵᠢᠶ᠎ᠡ᠂ ᠪᠤᠷᠤᠭᠤ checksum ᠢ ᠨᠢᠴᠠᠭᠠᠨ᠎ᠠ᠃ HD ᠬᠦᠯᠢᠶᠡᠨ ᠠᠪᠬᠤ/ᠬᠠᠷᠢᠭᠤᠯᠲᠠ ᠶᠢᠨ ᠰᠠᠯᠠᠭ᠎ᠠ᠂ index ᠢ ᠪᠢᠴᠢᠨ᠎ᠠ᠃ Bitcoin ᠤ ᠵᠠᠮ ᠲᠠᠢ ᠠᠳᠠᠯᠢ ᠭᠡᠵᠦ ᠦᠵᠡᠬᠦ ᠦᠭᠡᠢ᠃

## ᠪᠠᠲᠠᠯᠠᠭ᠎ᠠ ᠪᠠ ᠬᠢᠵᠠᠭᠠᠷ

RPC ᠶᠢ `127.0.0.1:18443` loopback᠂ ᠬᠤᠪᠢ ᠶᠢᠨ Bearer token ᠲᠠᠢ ᠠᠰᠠᠭᠠᠨ᠎ᠠ᠃ ᠬᠡᠲᠡᠪᠴᠢ ᠨᠡᠭᠡᠭᠡᠬᠦ᠂ ᠠᠯᠤᠰ ᠠᠴᠠ ᠵᠢᠷᠤᠬᠤ ᠦᠭᠡᠢ᠃ ᠳᠣᠲᠣᠭᠠᠳᠤ ᠦᠢᠯᠡᠴᠢᠯᠭᠡ ᠪᠤᠶᠤ ᠪᠠᠲᠠᠯᠠᠭᠳᠠᠭᠰᠠᠨ tunnel ᠠᠰᠢᠭᠯᠠᠨ᠎ᠠ᠃ Origin/Referer ᠨᠢᠴᠠᠭᠠᠨ᠎ᠠ᠃ JSON-RPC᠄ POST `/rpc`᠂ object/array `params`᠂ `id`᠃ notification᠄ HTTP 204᠃ ᠬᠢᠵᠠᠭᠠᠷ᠄ body 8004096 ᠪᠠᠢᠲ᠂ header 8192᠂ batch 16᠂ ᠵᠡᠷᠭᠡ ᠬᠦᠰᠡᠯᠲᠡ 16᠂ 10 ᠰᠧᠺᠦᠨᠳ᠂ limit 1–1000᠂ offset 0–1000000᠃ 28 ᠠᠷᠭ᠎ᠠ᠂ 11 REST ᠵᠠᠮ᠃

## ᠭᠦᠶᠦᠯᠭᠡᠭᠡ ᠪᠠ ᠪᠯᠣᠺ ᠬᠠᠢᠬᠤ

`getrawtransaction` ᠢᠳᠡᠪᠬᠢᠲᠡᠢ ᠬᠡᠯᠬᠢᠶ᠎ᠡ᠂ mempool ᠢ ᠬᠠᠢᠨ᠎ᠠ᠂ ᠬᠠᠶᠠᠭᠰᠠᠨ ᠰᠠᠯᠠᠭ᠎ᠠ ᠶᠢ ᠬᠠᠢᠬᠤ ᠦᠭᠡᠢ᠃ ᠣᠷᠣᠯᠲᠠ ᠡᠮᠦᠨᠡᠬᠢ ᠭᠠᠷᠤᠯᠲᠠ ᠶᠢ ᠵᠢᠭᠠᠨ᠎ᠠ᠂ ᠭᠠᠭᠴᠠ ᠢᠯᠡᠭᠡᠭᠴᠢ ᠶᠢᠨ ᠬᠠᠶᠢᠭ ᠪᠢᠰᠢ᠃ `getblock`᠄ Boolean `verbose`᠃ ᠢᠳᠡᠪᠬᠢ ᠦᠭᠡᠢ ᠪᠯᠣᠺ᠄ `active=false`᠂ `confirmations=-1`᠃ ᠪᠯᠣᠺ ᠤᠨ ᠬᠡᠱ ᠢᠶᠡᠷ ᠲᠡᠭᠦᠬᠡᠢ ᠭᠦᠶᠦᠯᠭᠡᠭᠡ ᠠᠪᠤᠨ᠎ᠠ᠃ `findspendingtransaction` ᠵᠥᠪᠬᠡᠨ ᠢᠳᠡᠪᠬᠢᠲᠡᠢ ᠪᠠᠲᠠᠯᠠᠭᠳᠠᠭᠰᠠᠨ ᠵᠠᠷᠯᠠᠭ᠎ᠠ ᠬᠠᠢᠨ᠎ᠠ᠃ null ᠨᠢ ᠠᠰᠢᠭᠯᠠᠬᠤ ᠪᠣᠯᠣᠮᠵᠢ ᠶᠢᠨ ᠨᠣᠲᠠᠯᠠᠭ᠎ᠠ ᠪᠢᠰᠢ᠃ `gettxout`᠂ `include_mempool=true` ᠰᠢᠯᠭᠠᠨ᠎ᠠ᠃ ᠪᠠᠲᠠᠯᠠᠭ᠎ᠠ᠂ ᠢᠳᠡᠪᠬᠢ ᠥᠭᠡᠷᠴᠢᠯᠡᠭᠳᠡᠵᠦ ᠪᠣᠯᠣᠨ᠎ᠠ᠃
