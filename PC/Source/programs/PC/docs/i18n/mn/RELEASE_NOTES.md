# SUMUWW · Хувилбарын тэмдэглэл

SUMUWW PC 0.57.46 · Зангилаа гинжний өгөгдлийг шалгаж, хадгалж, дамжуулж, лавлах боломж олгоно.

## Гарын үсгийн формат

Эх код дахь нэмэлт SDK нь түлхүүр болон сүлжээ ашиглахгүйгээр гүйлгээ угсарч, өгсөн гарын үсгийг шалгана. Энэ нь гарын үсэг зурах програм эсвэл зангилааны тушаал биш. P2WPKH хязгаар нь жишээний форматад хамаарна. Хувийн хэтэвчийг ашиглаж болно.

## RPC ба HTTP API

validateaddress шалгах нийлбэр болон сонгосон сүлжээг шалгана. decoderawtransaction-ийн decoded_only нь зөвхөн өгөгдөл тайлсныг заана; гарын үсгийн хүчинтэй байдал эсвэл баталгаажуулалт биш. OP_RETURN гаднын програмд өгөгдөл хадгална. Зангилаанд шимтгэл лавлах, илгээхийн өмнөх шалгалт, RBF орлуулалтын төлөв болон блокийн дарааллаар өгөгдөл унших боломж нэмэв. Хүлээгдэж буй гүйлгээг устгахаас өмнө орлуулах гүйлгээг шалгана. Олон гарын үсэг болон түгжээтэй гаралтыг тусгаарласан идэвхжүүлэлтийн туршилтад хэрэгжүүлсэн; нийтийн сүлжээнд хараахан идэвхжээгүй.

## Шалгалт

Хамаарлуудыг суулгаад эх кодоос python examples/node_contract.py ажиллуулна. Нийтэд ил туршилтын түлхүүр, түр regtest ашиглан илгээлт, татгалзалт, баталгаажуулалт, дахин зохион байгуулалт, өгөгдөл хадгалалтыг шалгана. Бодит хөрөнгө, хэрэглэгчийн профайл, гарын үсгийн төхөөрөмж ашиглахгүй.
