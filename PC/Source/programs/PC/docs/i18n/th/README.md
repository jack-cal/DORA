# SUMUWW · เอกสาร

SUMUWW PC 0.57.46 · โหนดตรวจสอบ เก็บ ส่งต่อ และให้ค้นข้อมูลเชน

## รูปแบบลายเซ็น

SDK ซอร์สที่เลือกใช้ได้ประกอบธุรกรรมและตรวจลายเซ็นโดยไม่ใช้กุญแจหรือเครือข่าย ไม่ใช่โปรแกรมลงนามหรือคำสั่งโหนด ข้อจำกัด P2WPKH ใช้กับรูปแบบตัวอย่างเท่านั้น ไม่ใช่โหนด กระเป๋าส่วนตัวเดิมยังใช้งานได้

## RPC และ HTTP API

validateaddress ตรวจเช็กซัมและเครือข่ายที่เลือก decoded_only จาก decoderawtransaction หมายถึงอ่านข้อมูลได้เท่านั้น ไม่ได้รับรองลายเซ็นหรือการยืนยัน OP_RETURN เก็บข้อมูลให้โปรแกรมภายนอก โหนดเพิ่มการสอบถามค่าธรรมเนียม การตรวจสอบก่อนส่ง สถานะการแทนที่ RBF และการอ่านข้อมูลตามลำดับบล็อก ระบบตรวจสอบธุรกรรมใหม่ก่อนลบธุรกรรมที่รออยู่ ลายเซ็นหลายชุดและเอาต์พุตแบบล็อกพัฒนาไว้สำหรับทดสอบการเปิดใช้ในระบบแยก ยังไม่เปิดใช้บนเครือข่ายสาธารณะ

## ผลการตรวจสอบ

ติดตั้งส่วนประกอบที่จำเป็นแล้วรัน python examples/node_contract.py จากซอร์ส กุญแจทดสอบสาธารณะและ regtest ชั่วคราวตรวจการส่ง การปฏิเสธ การยืนยัน การจัดเชนใหม่ และการเก็บข้อมูล โดยไม่ใช้เงินจริง โปรไฟล์ผู้ใช้ หรืออุปกรณ์ลงนาม

```text
network: sumuww (dora)
genesis: 00000032e243a8c71b449b13c2da733dd329f308a75aa4358f3f22707a28af97
HRP: sumuww
P2P magic: d052470c
1 SMW = 100000000 yugeon
```
