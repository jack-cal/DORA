# SUMUWW · சரிபார்ப்பு

SUMUWW PC 0.57.46 · முனை சங்கிலித் தரவைச் சரிபார்த்து, சேமித்து, பரப்பி, தேடலுக்கு வழங்குகிறது.

## கையொப்ப வடிவம்

விருப்பமான மூல SDK சாவி அல்லது பிணையம் இல்லாமல் பரிவர்த்தனைகளை அமைத்து, வழங்கப்பட்ட கையொப்பங்களைச் சரிபார்க்கிறது. இது கையொப்பமிடும் நிரலோ முனைக் கட்டளையோ அல்ல. P2WPKH வரம்பு எடுத்துக்காட்டின் வடிவத்துக்கே பொருந்தும்; முனைக்கல்ல. தனிப்பட்ட பணப்பையைப் பயன்படுத்தலாம்.

## சரிபார்ப்பு

தேவையான தொகுப்புகளை நிறுவி மூலத்திலிருந்து python examples/node_contract.py இயக்கவும். பொதுச் சோதனைச் சாவிகளும் தற்காலிக regtest-மும் சமர்ப்பித்தல், மறுப்பு, உறுதிப்படுத்தல், மறுசீரமைப்பு மற்றும் சேமிப்பைச் சோதிக்கின்றன. உண்மையான நிதி, பயனர் சுயவிவரம் அல்லது வன்பொருள் கையொப்பக் கருவி பயன்படுத்தப்படாது.

```powershell
python examples/node_contract.py
python -m unittest tests.test_node_contract tests.test_rpc -v
```
