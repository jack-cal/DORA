# SUMUWW · Документация

SUMUWW PC 0.57.46 · Узел проверяет, хранит, передаёт и предоставляет данные цепочки.

## Формат подписи

Необязательный SDK в исходниках собирает транзакции и проверяет переданные подписи без ключей и сети. Это не программа подписи и не команда узла. Ограничение P2WPKH относится к формату примера, а не к узлу. Прежний личный кошелёк доступен.

## RPC и HTTP API

validateaddress проверяет контрольную сумму и выбранную сеть. decoded_only от decoderawtransaction означает только разбор, а не проверку подписи или подтверждение. Выходы OP_RETURN сохраняют данные для внешних программ. Добавлены запрос комиссии, проверка перед отправкой, состояние замены RBF и чтение данных в порядке блоков. Замена проверяется до удаления ожидающих транзакций. Мультиподпись и блокировка выходов реализованы для изолированных испытаний активации; в публичной сети они пока не активированы.

## Проверка

Установив зависимости, запустите python examples/node_contract.py из исходников. Открытые тестовые ключи и временная regtest проверяют отправку, отказ, подтверждения, реорганизацию и сохранность данных. Реальные средства, профили пользователей и аппаратные устройства подписи не используются.

```text
network: sumuww (dora)
genesis: 00000032e243a8c71b449b13c2da733dd329f308a75aa4358f3f22707a28af97
HRP: sumuww
P2P magic: d052470c
1 SMW = 100000000 yugeon
```
