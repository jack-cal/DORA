# SUMUWW Android — release withdrawn

[All components](../README.md)

Android node releases 0.6.74 through 0.6.79 that implemented the height-9000 block-signature rule were withdrawn because their signing sequence did not match the intended design. No corrected Android node has been released.

Earlier Android releases predate the height-9000 rule and are historical records, not compatible replacements for a chain using that rule. Preserve your encrypted wallet and node data. Do not uninstall the app or clear its data merely because a release was withdrawn.
