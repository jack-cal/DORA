# SUMUWW Windows 0.57.13

Windows 64-bit wallet, mining application and independently validating node.

The application name is SUMUWW (SUMUWW) and its currency ticker is SMW. The existing icon is retained.
Extract the entire ZIP and run SUMUWW.exe. Keep SUMUWW-node.exe and _internal together.
Wallets, recovery words, balances and the existing blockchain remain compatible.
CPU mining is available from height zero. GPU and ASIC selection becomes available at verified chain height 12,000.
The interface and documentation support 34 language options.
