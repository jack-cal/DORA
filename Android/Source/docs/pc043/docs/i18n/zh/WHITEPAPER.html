白皮书摘要与现行规则

SUMUWW · 2026-10-26 · 2.3

SUMUWW是采用UTXO的独立SHA-256d链。1 SMW等于100,000,000 yugeon。矿工可领取新增发行奖励和区块内交易手续费。手续费转移现有币，不增加最大发行量。挖矿记录分别显示区块奖励总额与个人地址收到的金额。自动手续费依据当前本地待处理交易，手动费率单位为yugeon/vB。600秒的目标出块间隔并非确认时间保证。

从源区块9,600起，候选名单须有活动响应及链上锚定代际超过三分之二成员的批准。既有信标抽取三名见证人，事件抽取概率仍为20%。启用后，待完成任务可保留A/B区块对及事件信标，更新见证人选取轮次。旧响应归档，不混用不同轮次。证书不证明运营者相互独立或全球可达。准备记录、选中任务、完成证明是不同计数，11减9不能说明完成了2份证明。

从源区块9,600起，必须验证活跃见证人的选择证明。保留此前记录。请提前更新节点和钱包；旧版在累计工作量相同时可能选择不同的链。待处理任务的历史也会保留。
