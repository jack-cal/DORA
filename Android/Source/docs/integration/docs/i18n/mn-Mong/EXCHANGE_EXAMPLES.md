# SUMUWW Android 0.6.95 · ᠰᠢᠯᠭᠠᠯᠲᠠ

SUMUWW Android 0.6.95 · ᠵᠠᠩᠭᠢᠯᠠᠭ᠎ᠠ ᠨᠢ ᠥᠭᠭᠥᠭᠳᠡᠯ ᠢ ᠰᠢᠯᠭᠠᠵᠤ᠂ ᠬᠠᠳᠠᠭᠠᠯᠠᠵᠤ᠂ ᠳᠠᠮᠵᠢᠭᠤᠯᠤᠨ᠎ᠠ᠃

API ᠲᠣᠳᠣᠷᠬᠠᠶᠢᠯᠠᠯᠲᠠ ᠨᠢ ᠵᠠᠩᠭᠢᠯᠠᠭ᠎ᠠ ᠶᠢᠨ ᠴᠥᠮ᠎ᠡ ᠶᠢ ᠲᠠᠶᠢᠯᠪᠤᠷᠢᠯᠠᠨ᠎ᠠ᠃ Android ᠠᠫᠫ ᠳᠤ RPC ᠲᠣᠬᠢᠷᠠᠭᠤᠯᠭ᠎ᠠ ᠶᠢᠨ ᠳᠡᠯᠭᠡᠴᠡ ᠪᠠᠶᠢᠬᠤ ᠦᠭᠡᠢ᠃

## RPC ᠪᠠ HTTP API

validateaddress ᠨᠢ ᠰᠢᠯᠭᠠᠬᠤ ᠨᠡᠶᠢᠯᠡᠪᠦᠷᠢ ᠪᠣᠯᠤᠨ ᠰᠦᠯᠵᠢᠶ᠎ᠡ ᠶᠢ ᠰᠢᠯᠭᠠᠨ᠎ᠠ᠃ decoderawtransaction ᠤᠨ decoded_only ᠨᠢ ᠵᠥᠪᠬᠡᠨ ᠥᠭᠭᠥᠭᠳᠡᠯ ᠲᠠᠶᠢᠯᠤᠭᠰᠠᠨ ᠢ ᠵᠢᠭᠠᠨ᠎ᠠ᠃ OP_RETURN ᠨᠢ ᠭᠠᠳᠠᠨᠠᠬᠢ ᠫᠷᠣᠭᠷᠠᠮ ᠤᠨ ᠥᠭᠭᠥᠭᠳᠡᠯ ᠢ ᠬᠠᠳᠠᠭᠠᠯᠠᠨ᠎ᠠ᠃ ᠵᠠᠩᠭᠢᠯᠠᠭ᠎ᠠ ᠳᠤ ᠰᠢᠮᠲᠡᠭᠡᠯ ᠯᠠᠪᠯᠠᠬᠤ᠂ ᠢᠯᠡᠭᠡᠬᠦ ᠡᠴᠡ ᠡᠮᠦᠨ᠎ᠡ ᠰᠢᠯᠭᠠᠬᠤ᠂ RBF ᠣᠷᠣᠯᠠᠭᠤᠯᠤᠯᠲᠠ ᠪᠠ ᠪᠯᠣᠺ ᠤᠨ ᠳᠡᠰ ᠢᠶᠡᠷ ᠥᠭᠭᠥᠭᠳᠡᠯ ᠤᠩᠰᠢᠬᠤ ᠴᠢᠳᠠᠪᠤᠷᠢ ᠨᠡᠮᠡᠪᠡ᠃ ᠣᠷᠣᠯᠠᠬᠤ ᠭᠦᠶᠢᠯᠭᠡ ᠶᠢ ᠰᠢᠯᠭᠠᠭᠰᠠᠨ ᠤ ᠳᠠᠷᠠᠭ᠎ᠠ ᠬᠦᠯᠢᠶᠡᠵᠦ ᠪᠠᠶᠢᠭ᠎ᠠ ᠭᠦᠶᠢᠯᠭᠡ ᠶᠢ ᠤᠰᠠᠳᠬᠠᠨ᠎ᠠ᠃ ᠣᠯᠠᠨ ᠭᠠᠷ ᠤᠨ ᠦᠰᠦᠭ ᠪᠠ ᠲᠦᠭᠵᠢᠶ᠎ᠡ ᠲᠡᠢ ᠭᠠᠷᠤᠯᠲᠠ ᠶᠢ ᠲᠤᠰᠠᠭᠠᠷ ᠲᠤᠷᠰᠢᠯᠲᠠ ᠳᠤ ᠬᠡᠷᠡᠭᠵᠢᠭᠦᠯᠪᠡ᠃ ᠨᠡᠶᠢᠲᠡ ᠶᠢᠨ ᠰᠦᠯᠵᠢᠶ᠎ᠡ ᠳᠦ ᠬᠠᠷᠠᠬᠠᠨ ᠢᠳᠡᠪᠬᠢᠵᠢᠭᠡᠭᠦᠢ᠃

## ᠭᠦᠶᠦᠯᠭᠡᠭᠡ ᠪᠠ ᠪᠯᠣᠺ ᠬᠠᠢᠬᠤ

`getrawtransaction` ᠢᠳᠡᠪᠬᠢᠲᠡᠢ ᠬᠡᠯᠬᠢᠶ᠎ᠡ᠂ mempool ᠢ ᠬᠠᠢᠨ᠎ᠠ᠂ ᠬᠠᠶᠠᠭᠰᠠᠨ ᠰᠠᠯᠠᠭ᠎ᠠ ᠶᠢ ᠬᠠᠢᠬᠤ ᠦᠭᠡᠢ᠃ ᠣᠷᠣᠯᠲᠠ ᠡᠮᠦᠨᠡᠬᠢ ᠭᠠᠷᠤᠯᠲᠠ ᠶᠢ ᠵᠢᠭᠠᠨ᠎ᠠ᠂ ᠭᠠᠭᠴᠠ ᠢᠯᠡᠭᠡᠭᠴᠢ ᠶᠢᠨ ᠬᠠᠶᠢᠭ ᠪᠢᠰᠢ᠃ `getblock`᠄ Boolean `verbose`᠃ ᠢᠳᠡᠪᠬᠢ ᠦᠭᠡᠢ ᠪᠯᠣᠺ᠄ `active=false`᠂ `confirmations=-1`᠃ ᠪᠯᠣᠺ ᠤᠨ ᠬᠡᠱ ᠢᠶᠡᠷ ᠲᠡᠭᠦᠬᠡᠢ ᠭᠦᠶᠦᠯᠭᠡᠭᠡ ᠠᠪᠤᠨ᠎ᠠ᠃ `findspendingtransaction` ᠵᠥᠪᠬᠡᠨ ᠢᠳᠡᠪᠬᠢᠲᠡᠢ ᠪᠠᠲᠠᠯᠠᠭᠳᠠᠭᠰᠠᠨ ᠵᠠᠷᠯᠠᠭ᠎ᠠ ᠬᠠᠢᠨ᠎ᠠ᠃ null ᠨᠢ ᠠᠰᠢᠭᠯᠠᠬᠤ ᠪᠣᠯᠣᠮᠵᠢ ᠶᠢᠨ ᠨᠣᠲᠠᠯᠠᠭ᠎ᠠ ᠪᠢᠰᠢ᠃ `gettxout`᠂ `include_mempool=true` ᠰᠢᠯᠭᠠᠨ᠎ᠠ᠃ ᠪᠠᠲᠠᠯᠠᠭ᠎ᠠ᠂ ᠢᠳᠡᠪᠬᠢ ᠥᠭᠡᠷᠴᠢᠯᠡᠭᠳᠡᠵᠦ ᠪᠣᠯᠣᠨ᠎ᠠ᠃
