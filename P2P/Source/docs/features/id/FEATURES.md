# SUMUWW P2P Full / Light 0.3.6

P2P menyediakan biaya menurut antrean saat ini, tarif manual, dan kenaikan setelah konfirmasi. Membatalkan pratinjau yang belum dikirim membebaskan dana cadangan. Pengembalian hanya memerlukan rantai tempat dana Anda berada. Jumlah dan cadangan biaya yang disepakati tetap.

1 yugeon = 0.00000001 SMW

Setorkan SMW untuk menjual atau BTC untuk membeli beserta biaya jaringan, lalu tunggu konfirmasi. Dana dialokasikan secara lokal per pesanan dan diperiksa lagi sebelum perdagangan; alokasi bukan penguncian di blockchain. Judul dan deskripsi dihapus. Tombol Berdagang di samping pesanan membuka pertukaran. Penemuan otomatis, koneksi ulang dan TLS 1.3 dua arah menggantikan pengisian IP rekan secara manual. Penemuan Internet memerlukan rekan terbaru yang dapat dijangkau; tidak semua router atau firewall dapat dilewati. Program kedua pihak harus diperbarui.
