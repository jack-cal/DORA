# SUMUWW P2P Full / Light 0.3.6

P2P支援按目前待處理交易自動計算手續費、手動費率及確認後加費。取消未傳送的預覽會釋放預留資金。退款只需連接存放自己資金的鏈。約定金額與手續費儲備保持不變。

1 yugeon = 0.00000001 SMW

賣出須存入SMW，買入須存入BTC，並預留網絡手續費、等候確認。程式按訂單在本機分配資金，交易前會再次核對；分配不等於鏈上鎖定。標題與描述已移除，按訂單旁的交易按鈕開始兌換。自動搜尋、重新連線及雙向TLS 1.3通訊取代手動輸入對方IP。互聯網搜尋需要可連線的新版節點，無法穿透所有路由器或防火牆。交易雙方均須更新程式。
