# SUMUWW P2P Full / Light 0.3.6

P2P рассчитывает комиссии по текущей очереди, поддерживает ручную ставку и повышение после подтверждения. Отмена неотправленного предпросмотра освобождает резерв. Для возврата нужна только цепь с вашими средствами. Согласованные суммы и резервы комиссии не меняются.

1 yugeon = 0.00000001 SMW

Для продажи внесите SMW, для покупки — BTC, включая сетевые комиссии, и дождитесь подтверждений. Средства распределяются по ордерам локально и проверяются повторно перед обменом; это не блокировка в цепочке. Заголовки и описания удалены. Кнопка обмена рядом с ордером открывает сделку. Автопоиск, переподключение и двусторонний TLS 1.3 заменяют ручной ввод IP контрагента. Для поиска в Интернете нужны доступные обновлённые узлы; обход всех маршрутизаторов и межсетевых экранов не гарантируется. Обновить программу должны обе стороны.
