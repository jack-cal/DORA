# SUMUWW P2P Full / Light 0.3.4

Перед отправкой подписанной транзакции SUMUWW программа P2P проверяет её через подключённый узел. При отказе транзакция не отправляется. Согласованные суммы обмена и комиссии не меняются; комиссии Bitcoin используют собственные единицы.

`1 yugeon = 0.00000001 SMW`

`1 SMW = 100,000,000 yugeon`
