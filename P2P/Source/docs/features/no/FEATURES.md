# SUMUWW P2P Full / Light 0.3.5

P2P tilbyr gebyrer etter gjeldende kø, manuelle satser og bekreftede økninger. Kansellering av en usendt forhåndsvisning frigjør reserverte midler. Tilbakebetaling krever bare kjeden med dine midler. Avtalte beløp og gebyrreserver er uendret.

1 yugeon = 0.00000001 SMW
