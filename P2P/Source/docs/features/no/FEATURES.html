SUMUWW P2P Full / Light 0.3.6

P2P tilbyr gebyrer etter gjeldende kø, manuelle satser og bekreftede økninger. Kansellering av en usendt forhåndsvisning frigjør reserverte midler. Tilbakebetaling krever bare kjeden med dine midler. Avtalte beløp og gebyrreserver er uendret.

1 yugeon = 0.00000001 SMW

Sett inn SMW for å selge eller BTC for å kjøpe, med nettverksgebyrer, og vent på bekreftelser. Midler fordeles lokalt per ordre og kontrolleres igjen før handel; fordelingen er ikke en låsing på blokkjeden. Titler og beskrivelser er fjernet. Handle-knappen ved ordren åpner byttet. Automatisk oppdagelse, ny tilkobling og toveis TLS 1.3 erstatter manuell inntasting av motpartens IP. Oppdagelse på Internett krever tilgjengelige, oppdaterte noder og omgår ikke alle rutere eller brannmurer. Begge programmene må oppdateres.
