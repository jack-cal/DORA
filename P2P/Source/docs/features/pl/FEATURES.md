# SUMUWW P2P Full / Light 0.3.4

P2P sprawdza podpisaną transakcję SUMUWW w podłączonym węźle przed jej rozgłoszeniem. Odrzucenie wstrzymuje rozgłoszenie. Uzgodnione kwoty wymiany i opłaty pozostają stałe; opłaty Bitcoin zachowują własne jednostki.

`1 yugeon = 0.00000001 SMW`

`1 SMW = 100,000,000 yugeon`
