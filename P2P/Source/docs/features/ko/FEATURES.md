# SUMUWW P2P Full / Light 0.3.6

P2P는 현재 대기 거래를 기준으로 한 자동 수수료, 직접 입력, 확인 후 수수료 올리기를 지원합니다. 미전송 미리보기를 취소하면 예약 잔액을 해제합니다. 환불에는 내 자금이 있는 체인만 필요합니다. 합의한 금액과 수수료 예비금은 유지합니다.

1 yugeon = 0.00000001 SMW

매도하려면 SMW, 매수하려면 BTC를 네트워크 수수료와 함께 입금하고 확인을 기다리세요. 거래별 자금은 프로그램에서 중복 사용을 막도록 배정하고 거래 전에 다시 확인합니다. 이 배정 자체가 블록체인에 자금을 잠그는 것은 아닙니다. 제목과 상세내용은 제거했습니다. 거래 옆의 거래 버튼으로 교환을 시작합니다. 자동 탐색·재연결과 양방향 TLS 1.3 통신을 적용해 상대 IP를 직접 입력하지 않습니다. 인터넷 탐색에는 접속 가능한 최신 프로그램이 필요하며 모든 공유기·방화벽을 통과하는 것은 아닙니다. 거래하는 양쪽 프로그램을 업데이트해야 합니다.
