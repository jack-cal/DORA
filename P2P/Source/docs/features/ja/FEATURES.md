# SUMUWW P2P Full / Light 0.3.6

P2Pは現在の待機取引に基づく手数料、手動設定、確認後の増額に対応します。未送信のプレビューを取り消すと予約資金を解放します。返金に必要なのは自分の資金があるチェーンだけです。合意済みの金額と手数料予備金は維持します。

1 yugeon = 0.00000001 SMW

売る場合はSMW、買う場合はBTCをネットワーク手数料とともに入金し、承認を待ってください。注文ごとに資金をローカルで割り当て、取引前に再確認します。この割り当てはオンチェーンのロックではありません。件名と説明は削除しました。注文の横の取引ボタンで交換を開始します。自動検出・再接続と双方向TLS 1.3通信により、相手のIPを手入力する必要はありません。インターネットでの検出には接続可能な更新済みのピアが必要で、すべてのルーターやファイアウォールを通過できるわけではありません。双方のプログラムを更新してください。
