# SUMUWW P2P Full / Light 0.3.4

Antes de transmitir uma transação SUMUWW assinada, o P2P verifica-a no nó ligado. Se for rejeitada, não a transmite. Os valores e as taxas acordados na troca mantêm-se; as taxas Bitcoin usam as suas próprias unidades.

`1 yugeon = 0.00000001 SMW`

`1 SMW = 100,000,000 yugeon`
