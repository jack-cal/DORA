# SUMUWW P2P Full / Light 0.3.5

P2P нь одоогийн дараалалд тулгуурласан шимтгэл, гараар тохируулах хувь, баталгаажуулсны дараах шимтгэл нэмэлтийг дэмжинэ. Илгээгээгүй урьдчилсан харагдацыг цуцлахад нөөцөлсөн хөрөнгө чөлөөлөгдөнө. Буцаалтад өөрийн хөрөнгө байгаа хэлхээ л хэрэгтэй. Тохирсон дүн, шимтгэлийн нөөц өөрчлөгдөхгүй.

1 yugeon = 0.00000001 SMW
