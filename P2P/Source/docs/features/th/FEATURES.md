# SUMUWW P2P Full / Light 0.3.6

P2P รองรับค่าธรรมเนียมตามคิวปัจจุบัน อัตราที่กำหนดเอง และการเพิ่มค่าธรรมเนียมหลังยืนยัน การยกเลิกตัวอย่างที่ยังไม่ส่งจะคืนยอดที่จองไว้ การคืนเงินต้องใช้เฉพาะเชนที่ถือเงินของคุณ จำนวนและเงินสำรองค่าธรรมเนียมที่ตกลงไว้ไม่เปลี่ยน

1 yugeon = 0.00000001 SMW

ฝาก SMW เพื่อขายหรือ BTC เพื่อซื้อ พร้อมค่าธรรมเนียมเครือข่าย แล้วรอการยืนยัน โปรแกรมจัดสรรเงินแยกตามคำสั่งและตรวจซ้ำก่อนซื้อขาย การจัดสรรนี้ไม่ใช่การล็อกเงินบนเชน นำชื่อเรื่องและคำอธิบายออกแล้ว กดปุ่มซื้อขายข้างคำสั่งเพื่อเปิดการแลกเปลี่ยน ระบบค้นหาเพียร์และเชื่อมต่อใหม่อัตโนมัติผ่าน TLS 1.3 สองทิศทาง แทนการกรอก IP ของคู่ซื้อขาย การค้นหาผ่านอินเทอร์เน็ตต้องมีเพียร์รุ่นใหม่ที่เข้าถึงได้ และไม่สามารถผ่านเราเตอร์หรือไฟร์วอลล์ได้ทุกแบบ ทั้งสองฝ่ายต้องอัปเดตโปรแกรม
