# SUMUWW P2P Full / Light 0.3.6

Το P2P υποστηρίζει τέλη βάσει της τρέχουσας ουράς, χειροκίνητες χρεώσεις και επιβεβαιωμένες αυξήσεις. Η ακύρωση μη απεσταλμένης προεπισκόπησης αποδεσμεύει χρήματα. Η επιστροφή απαιτεί μόνο την αλυσίδα που κρατά τα χρήματά σας. Συμφωνημένα ποσά και αποθέματα τελών μένουν σταθερά.

1 yugeon = 0.00000001 SMW

Καταθέστε SMW για πώληση ή BTC για αγορά, μαζί με τα τέλη δικτύου, και περιμένετε επιβεβαιώσεις. Τα χρήματα κατανέμονται τοπικά ανά εντολή και ελέγχονται ξανά πριν τη συναλλαγή· αυτό δεν είναι δέσμευση στην αλυσίδα. Αφαιρέθηκαν τίτλοι και περιγραφές. Το κουμπί Συναλλαγή δίπλα στην εντολή ανοίγει την ανταλλαγή. Αυτόματη ανακάλυψη, επανασύνδεση και αμφίδρομο TLS 1.3 αντικαθιστούν τη χειροκίνητη εισαγωγή IP του αντισυμβαλλομένου. Η ανακάλυψη μέσω Internet απαιτεί προσβάσιμους ενημερωμένους κόμβους και δεν παρακάμπτει κάθε δρομολογητή ή τείχος προστασίας. Απαιτείται ενημέρωση και των δύο προγραμμάτων.
