# SUMUWW P2P Full / Light 0.3.4

Το P2P ελέγχει κάθε υπογεγραμμένη συναλλαγή SUMUWW στον συνδεδεμένο κόμβο πριν τη μεταδώσει. Αν απορριφθεί, δεν μεταδίδεται. Τα συμφωνημένα ποσά και τέλη ανταλλαγής παραμένουν σταθερά· τα τέλη Bitcoin χρησιμοποιούν δικές τους μονάδες.

`1 yugeon = 0.00000001 SMW`

`1 SMW = 100,000,000 yugeon`
