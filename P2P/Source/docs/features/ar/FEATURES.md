# SUMUWW P2P Full / Light 0.3.6

يدعم P2P رسومًا حسب قائمة الانتظار الحالية، ومعدلًا يدويًا، وزيادة بعد التأكيد. إلغاء المعاينة غير المرسلة يحرر الأموال المحجوزة. الاسترداد يحتاج فقط إلى السلسلة التي تحتفظ بأموالك. تبقى المبالغ واحتياطيات الرسوم المتفق عليها ثابتة.

1 yugeon = 0.00000001 SMW

أودع SMW للبيع أو BTC للشراء مع رسوم الشبكة وانتظر التأكيدات. تُخصص الأموال محلياً لكل طلب وتُفحص مجدداً قبل التداول؛ التخصيص ليس حجزاً على السلسلة. أُزيلت العناوين والأوصاف. يفتح زر التداول بجانب الطلب عملية المبادلة. يحل الاكتشاف التلقائي وإعادة الاتصال واتصال TLS 1.3 ثنائي الاتجاه محل إدخال عنوان IP للطرف الآخر. يتطلب الاكتشاف عبر الإنترنت أقراناً محدثين يمكن الوصول إليهم، ولا يتجاوز جميع أجهزة التوجيه أو جدران الحماية. يجب تحديث البرنامج لدى الطرفين.
