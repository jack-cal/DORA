# SUMUWW P2P Full / Light 0.3.4

P2P comprueba cada transacción SUMUWW firmada con el nodo conectado antes de difundirla. Si la comprobación la rechaza, no se difunde. Los importes y las comisiones acordados se mantienen; Bitcoin conserva sus propias unidades de comisión.

`1 yugeon = 0.00000001 SMW`

`1 SMW = 100,000,000 yugeon`
