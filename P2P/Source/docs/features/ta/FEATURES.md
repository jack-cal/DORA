P2P தற்போதைய வரிசைப்படி கட்டணம், கைமுறை விகிதம், உறுதிப்படுத்திய பின் கட்டண உயர்வு ஆகியவற்றை வழங்குகிறது. அனுப்பாத முன்னோட்டத்தை ரத்து செய்தால் ஒதுக்கிய நிதி விடுவிக்கப்படும். பணத்தைத் திரும்பப் பெற உங்கள் நிதி உள்ள சங்கிலி மட்டும் தேவை. ஒப்புக்கொண்ட தொகையும் கட்டண இருப்பும் மாறாது.

விற்க SMW அல்லது வாங்க BTC ஆகியவற்றைப் பிணையக் கட்டணத்துடன் வைப்பிட்டு உறுதிப்படுத்தல்களுக்காகக் காத்திருக்கவும். ஒவ்வொரு ஆர்டருக்கும் நிதி உள்ளூரில் ஒதுக்கப்பட்டு வர்த்தகத்திற்கு முன் மீண்டும் சரிபார்க்கப்படும்; இது சங்கிலியில் நிதியைப் பூட்டுவது அல்ல. தலைப்பும் விளக்கமும் அகற்றப்பட்டன. ஆர்டருக்கு அருகிலுள்ள வர்த்தகப் பொத்தான் பரிமாற்றத்தைத் திறக்கும். தானியங்கு கண்டறிதல், மீண்டும் இணைத்தல் மற்றும் இருவழி TLS 1.3 மூலம் எதிர்தரப்பின் IP-ஐ கைமுறையாக உள்ளிட வேண்டியதில்லை. இணையக் கண்டறிதலுக்கு அணுகக்கூடிய புதுப்பிக்கப்பட்ட இணை முனைகள் தேவை; எல்லா திசைவிகளையும் தீச்சுவர்களையும் கடக்க இயலாது. இரு தரப்பு நிரல்களும் புதுப்பிக்கப்பட வேண்டும்.
