# SUMUWW P2P Full / Light 0.3.6

P2P支援依目前待處理交易自動計算手續費、手動費率及確認後加費。取消未傳送的預覽會釋放預留資金。退款只需連接存放自己資金的鏈。約定金額與手續費準備金保持不變。

1 yugeon = 0.00000001 SMW

賣出須存入SMW，買入須存入BTC，並預留網路手續費、等待確認。程式按訂單在本機分配資金並在交易前複核；分配不等於鏈上鎖定。標題與說明已移除，點選訂單旁的交易按鈕開始兌換。自動探索、重新連線和雙向TLS 1.3通訊取代手動輸入對方IP。網際網路探索需要可連線的新版節點，無法穿透所有路由器或防火牆。交易雙方均須更新程式。
