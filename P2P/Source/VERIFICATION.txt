SUMUWW P2P 0.3.6 — local verification, 26 October 2026

Source test suite: 160 tests, 928.408 seconds: 159 passed, one real-LAN test
skipped because this host had no RFC1918 LAN interface. Tests include Full,
Light and mixed-edition disposable SMW/BTC exchanges, both directions, actual
claims/refunds, restart/recovery, reorganization and server-outage handling.

New checks cover wallet/deposit/fee gating, duplicate input allocation,
allocation recovery, maker/taker rechecks, no title/detail inputs, per-row
native Trade buttons in 34 languages, TLS-only connections, certificate key
pins, malformed routes, forged discovery beacons and local-address filtering.
A three-process shared-peer route completed both on-chain claims without a
direct connection or counterparty IP entry between the trading participants.

Both rebuilt Full and Light 0.3.6 executables passed separate frozen checks:
native controls and language changes in 34 languages, encrypted peer connection,
wallet creation and rejection of posting without funding. Frozen checks do not
claim funded mainnet settlement. Source tests used disposable test chains.

Public discovery observation: DHT routers replied; automatic trading peer
connection was true during the observation.
This is not verification across separate Internet connections or arbitrary NATs.
No production wallet was opened, no mainnet coins were transferred, no firewall
or router rules were changed. These checks preceded GitHub publication.

English remains the first-launch default. Existing language choices and wallet
data remain separate from distribution files. The executables are unsigned.
General send-to-any-address wallet transfers are outside this release.
