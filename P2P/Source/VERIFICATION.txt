All Bitcoin headers validated from genesis through height 972639 on three public TLS servers.
Initial raw header storage: 77,811,200 bytes. Initial wire download: 155,659,439 bytes.
Initial measured duration: 205.34 seconds; not a performance guarantee.
Subsequent height: 972640; header storage: 77811280 bytes.
A confirmed public transaction's raw bytes and Merkle inclusion proof were checked.
No wallet was created for that public check and no mainnet transaction was sent.
This implementation uses Electrum, not BIP157 compact filters.

WHAT WAS NOT ESTABLISHED
Independent security audit, native-speaker review of every language, Internet-scale
marketplace discovery, NAT traversal, public-money settlement, guaranteed server honesty,
complete SPV transaction validation, guaranteed observation of every spend, automatic
fee replacement or unattended deadline monitoring. No proof of server operator independence.
Light requires honest available data sources. False omission/collusion remains possible.
Full requires synchronized unpruned Bitcoin Core with txindex and authenticated local RPC.
Both require a synchronized current SUMUWW full node, compatible counterparties and fees.
Windows executables are unsigned. Blockchain storage is additional to the ZIP size.

PRESERVED RULES
Valid legacy SUMUWW blocks <=8999 remain usable. Old-rule blocks >=9000 are rejected.
20% asynchronous connection proofs and DGW every ten blocks remain unchanged.
Issuance and halvings are unchanged. HTLC funding requires activation at height 9100.
Existing user wallets, ordinary-wallet apps, full nodes and chain databases were not modified.

REPRODUCIBILITY

Run tests with PYTHONPATH=.;vendor;tests and python -m unittest discover -s tests -v.

checks the corresponding packaged UI. Light also supports --light-server-check
with a new --data-dir for a read-only TLS probe; it is not a full header/proof check.
