# SUMUWW Explorer 0.4.10

Прегледач приказује стопе накнада у yugeon/vB. Ако је локални чвор забележио замену, страница трансакције води до нове трансакције. Потврђени подаци ланца имају предност; локална историја замена је ограничена.

`1 yugeon = 0.00000001 SMW`

`1 SMW = 100,000,000 yugeon`

Истраживач приказује откривене услове вишеструког потписа и закључавања излаза. Активирање на јавној мрежи још није заказано.


Историја рударења одвојено приказује ново издавање, накнаде и укупну награду сваког блока. Износ примљен у ваш новчаник приказује се засебно. При делимичном преузимању не претпоставља се расподела између две ставке. Чвор нуди 28 RPC метода, укључујући процену накнада, и проверава и прослеђује потписане трансакције.
