SUMUWW Explorer 0.4.11

エクスプローラーは手数料率を yugeon/vB で表示します。ローカルノードに取引の置き換え記録がある場合、取引画面から新しい取引を開けます。チェーン上の確定記録を優先し、ローカルの置き換え履歴には件数制限があります。

1 yugeon = 0.00000001 SMW

1 SMW = 100,000,000 yugeon

エクスプローラーで公開済みの複数署名・出力ロック条件を確認できます。公開ネットワークでの有効化日程は未定です。

採掘履歴では、各ブロックの新規発行報酬、取引手数料報酬、合計を分けて表示します。自分のウォレットが受け取った額は別に表示します。報酬の一部しか請求されていない場合、内訳を推定しません。ノードは手数料推定を含む28個のRPCメソッドを提供し、署名済み取引を検証・中継します。
