# SUMUWW Explorer 0.4.11

탐색기는 수수료율을 yugeon/vB로 표시합니다. 로컬 노드에 거래 교체 기록이 있으면 거래 화면에서 새 거래로 이동할 수 있습니다. 체인에서 확인된 기록을 우선하며, 로컬 교체 이력은 제한되어 있습니다.

`1 yugeon = 0.00000001 SMW`

`1 SMW = 100,000,000 yugeon`

탐색기에서 공개된 다중 서명·출력 잠금 조건을 확인할 수 있습니다. 운영망 활성화 일정은 아직 정해지지 않았습니다.


채굴 내역에서 블록별 신규 발행 보상, 거래 수수료 보상, 총보상을 구분합니다. 내 지갑이 받은 금액은 별도로 표시합니다. 보상을 일부만 청구한 경우에는 두 항목의 지급액을 임의로 나누지 않습니다. 노드는 수수료 추정을 포함한 RPC 28개를 제공하고, 서명된 거래를 검증·전파합니다.
