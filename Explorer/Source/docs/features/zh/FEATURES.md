# SUMUWW Explorer 0.4.10

浏览器以 yugeon/vB 显示费率。如果本地节点记录了交易替换，交易页面会提供新交易的链接。以链上确认记录为准，本地替换历史的保存数量有限。

`1 yugeon = 0.00000001 SMW`

`1 SMW = 100,000,000 yugeon`

浏览器显示已公开的多重签名和输出锁定条件。主网启用时间尚未确定。


挖矿记录分别显示每个区块的新增发行奖励、交易手续费奖励和总奖励，钱包实际收到的金额单独显示。若只领取了部分奖励，不会擅自推定两类奖励的分配。节点提供 28 个 RPC 方法，包括手续费估算，并验证和转发已签名交易。
