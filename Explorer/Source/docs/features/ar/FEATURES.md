# SUMUWW Explorer 0.4.10

يعرض المستكشف معدلات الرسوم بوحدة yugeon/vB. إذا سجّلت العقدة المحلية استبدال معاملة، تعرض صفحتها رابطًا للمعاملة الجديدة. تكون الأولوية للسجلات المؤكدة في السلسلة، وسجل الاستبدالات المحلي محدود.

`1 yugeon = 0.00000001 SMW`

`1 SMW = 100,000,000 yugeon`

يعرض المستكشف شروط التوقيع المتعدد وقفل المخرجات بعد كشفها. لم يُحدد موعد تفعيلها على الشبكة العامة بعد.


يفصل سجل التعدين بين الإصدار الجديد ورسوم المعاملات وإجمالي مكافأة كل كتلة. يظهر المبلغ الذي تلقته محفظتك بشكل منفصل. عند المطالبة بجزء من المكافأة، لا يُفترض توزيع المبلغ بين المكونين. توفر العقدة 28 طريقة RPC، بما فيها تقدير الرسوم، وتتحقق من المعاملات الموقعة وتنقلها.
