# SUMUWW Explorer 0.4.11

Ipinapakita ng explorer ang singil sa yugeon/vB. Kung naitala ng lokal na node ang pagpapalit, may link ang pahina ng transaksiyon patungo sa kapalit nito. Mas pinapahalagahan ang mga nakumpirmang tala sa chain; limitado ang lokal na kasaysayan ng pagpapalit.

`1 yugeon = 0.00000001 SMW`

`1 SMW = 100,000,000 yugeon`

Ipinapakita ng explorer ang mga naibunyag na kundisyon ng maraming lagda at pag-lock ng output. Wala pang iskedyul ng pag-activate sa pampublikong network.


Hiwalay sa kasaysayan ng pagmimina ang bagong inilabas, bayarin sa transaksyon, at kabuuang gantimpala ng bawat block. Hiwalay ding ipinapakita ang natanggap ng iyong wallet. Kapag bahagi lamang ang kinuha, hindi ipinapalagay ang paghahati ng dalawang sangkap. May 28 RPC method ang node, kabilang ang pagtatantiya ng bayarin, at sinusuri at ipinapasa nito ang mga nilagdaang transaksyon.
