ตัวสำรวจแสดงอัตราค่าธรรมเนียมเป็น yugeon/vB หากโหนดในเครื่องบันทึกการแทนที่ธุรกรรมไว้ หน้าธุรกรรมจะมีลิงก์ไปยังธุรกรรมใหม่ โดยยึดข้อมูลที่ยืนยันบนเชนก่อน และเก็บประวัติการแทนที่ในเครื่องในจำนวนจำกัด

1 yugeon = 0.00000001 SMW

1 SMW = 100,000,000 yugeon

ตัวสำรวจแสดงเงื่อนไขหลายลายเซ็นและการล็อกเอาต์พุตที่เปิดเผยแล้ว ยังไม่กำหนดวันเปิดใช้บนเครือข่ายสาธารณะ

ประวัติการขุดแยกเหรียญออกใหม่ ค่าธรรมเนียมธุรกรรม และรางวัลรวมของแต่ละบล็อก โดยแสดงยอดที่กระเป๋าของคุณได้รับแยกต่างหาก หากรับรางวัลเพียงบางส่วน ระบบจะไม่คาดเดาการแบ่งยอดทั้งสองส่วน โหนดมี RPC 28 วิธี รวมการประมาณค่าธรรมเนียม และตรวจสอบพร้อมส่งต่อธุรกรรมที่ลงนามแล้ว
