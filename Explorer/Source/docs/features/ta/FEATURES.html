ஆய்வி கட்டண விகிதத்தை yugeon/vB அலகில் காட்டுகிறது. பரிவர்த்தனை மாற்றப்பட்டதை உள்ளூர் முனை பதிவு செய்திருந்தால், அதன் பக்கம் புதிய பரிவர்த்தனைக்கு இணைப்பு தரும். சங்கிலியில் உறுதிசெய்யப்பட்ட பதிவுகளுக்கு முன்னுரிமை உண்டு; உள்ளூர் மாற்ற வரலாறு வரம்புக்குட்பட்டது.

1 yugeon = 0.00000001 SMW

1 SMW = 100,000,000 yugeon

வெளிப்படுத்தப்பட்ட பல கையொப்ப மற்றும் வெளியீட்டுப் பூட்டு நிபந்தனைகளை ஆய்வி காட்டுகிறது. பொதுவலையில் செயல்படுத்தும் தேதி இன்னும் தீர்மானிக்கப்படவில்லை.

சுரங்க வரலாற்றில் ஒவ்வொரு தொகுதியின் புதிய வெளியீடு, பரிவர்த்தனைக் கட்டணம், மொத்த வெகுமதி தனித்தனியாகக் காட்டப்படும். உங்கள் பணப்பை பெற்ற தொகை தனியாகக் காட்டப்படும். ஒரு பகுதி மட்டுமே பெறப்பட்டால் இரு கூறுகளின் பங்குகள் ஊகிக்கப்படாது. கட்டண மதிப்பீடு உட்பட 28 RPC முறைகளை முனை வழங்குகிறது; கையொப்பமிட்ட பரிவர்த்தனைகளைச் சரிபார்த்து அனுப்புகிறது.
