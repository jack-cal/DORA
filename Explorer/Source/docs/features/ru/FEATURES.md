# SUMUWW Explorer 0.4.11

Обозреватель показывает ставки комиссии в yugeon/vB. Если локальный узел сохранил запись о замене, страница транзакции содержит ссылку на новую транзакцию. Подтверждённые данные цепи имеют приоритет; локальная история замен ограничена.

`1 yugeon = 0.00000001 SMW`

`1 SMW = 100,000,000 yugeon`

Обозреватель показывает раскрытые условия мультиподписи и блокировки выходов. Дата активации в публичной сети пока не назначена.


История майнинга отдельно показывает новую эмиссию, комиссии и общую награду каждого блока. Сумма, полученная вашим кошельком, указана отдельно. При частичном получении награды её распределение между двумя составляющими не предполагается. Узел предоставляет 28 методов RPC, включая оценку комиссии, проверяет и передаёт подписанные транзакции.
