# SUMUWW Explorer 0.4.10

Utforskeren viser gebyrsatser i yugeon/vB. Har den lokale noden registrert en erstatning, lenker transaksjonssiden til den nye transaksjonen. Bekreftede kjededata har forrang; lokal erstatningshistorikk er begrenset.

`1 yugeon = 0.00000001 SMW`

`1 SMW = 100,000,000 yugeon`

Utforskeren viser avslørte vilkår for flere signaturer og låste utganger. Aktivering i det offentlige nettverket er ennå ikke planlagt.


Utvinninghistorikken viser ny utstedelse, gebyrer og samlet belønning for hver blokk hver for seg. Beløpet lommeboken din mottar vises separat. Ved delvis uttak antas ingen fordeling mellom de to delene. Noden tilbyr 28 RPC-metoder, inkludert gebyrestimering, og kontrollerer og videresender signerte transaksjoner.
