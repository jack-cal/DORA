# SUMUWW Explorer 0.4.10

Utforskaren visar avgiftssatser i yugeon/vB. Om den lokala noden har registrerat en ersättning länkar transaktionssidan till den nya transaktionen. Bekräftade kedjedata har företräde; den lokala ersättningshistoriken är begränsad.

`1 yugeon = 0.00000001 SMW`

`1 SMW = 100,000,000 yugeon`

Utforskaren visar avslöjade villkor för flera signaturer och låsta utgångar. Aktivering i det offentliga nätverket är ännu inte planerad.


Utvinningshistoriken visar ny utgivning, avgifter och total belöning för varje block var för sig. Beloppet din plånbok tar emot visas separat. Vid delvis uttag antas ingen fördelning mellan delarna. Noden erbjuder 28 RPC-metoder, inklusive avgiftsuppskattning, och kontrollerar och vidarebefordrar signerade transaktioner.
