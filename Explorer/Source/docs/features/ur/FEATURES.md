# SUMUWW Explorer 0.4.10

ایکسپلورر فیس کی شرح yugeon/vB میں دکھاتا ہے۔ اگر مقامی نوڈ نے لین دین کی تبدیلی درج کی ہو تو اس کے صفحے پر نئے لین دین کا ربط ملتا ہے۔ چین میں تصدیق شدہ ریکارڈ کو ترجیح دی جاتی ہے؛ تبدیلیوں کی مقامی تاریخ محدود ہے۔

`1 yugeon = 0.00000001 SMW`

`1 SMW = 100,000,000 yugeon`

ایکسپلورر ظاہر شدہ کثیر دستخط اور آؤٹ پٹ لاک کی شرائط دکھاتا ہے۔ عوامی نیٹ ورک پر فعال کرنے کی تاریخ ابھی مقرر نہیں ہوئی۔


مائننگ کی تاریخ ہر بلاک کا نیا اجرا، لین دین کی فیس اور کل انعام الگ دکھاتی ہے۔ آپ کے والیٹ کو موصول رقم الگ ظاہر ہوتی ہے۔ جزوی وصولی پر دونوں حصوں کی تقسیم فرض نہیں کی جاتی۔ نوڈ فیس کے تخمینے سمیت 28 RPC طریقے فراہم کرتا ہے اور دستخط شدہ لین دین کی توثیق اور ترسیل کرتا ہے۔
