# SUMUWW Explorer

[All components](../README.md) · [Release notes](https://github.com/jack-cal/SUMUWW/releases/tag/explorer-v0.4.2)

The explorer reads a selected local SUMUWW node database and provides block, transaction, address and mining-analysis views. It maintains its own search index.

## Use

Extract the Windows ZIP and run `start-explorer.cmd`. The local interface opens at `http://127.0.0.1:8770`. Select the synchronized node database to inspect. The explorer does not send coins or access wallet keys.
